# Wolf Tracks (iOS/Swift)

Wolf Tracks is a research focused pedestrian counting app that allows for real-time data collection and visualization, with the ability to import and export data to compatible spreadsheet formats.

## Features
- Real-time data collection
- Data visualization in table and chart form
- Quick location access for visualization
- Ability to add field notes
- Export and import field notes and pedestrian data to compatible formats
